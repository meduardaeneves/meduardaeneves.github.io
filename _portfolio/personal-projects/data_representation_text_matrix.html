Project Goal

  • The project has the goal to develop a matrix from an .txt text
  • After the matrix was the developed, the project also converts it back into the original text

Project Development

  • The technical development of this project was divided into four phases:
    • Data Load
    • Text modification to list format
    • Text to matrix conversion
    • Matrix to text conversion
