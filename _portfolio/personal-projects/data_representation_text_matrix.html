This page will present, in English, the project's goal, the process used to develop it and the results.

Project Goal

  • The project has the goal to develop a matrix from a .txt text
  • After the matrix was the developed, the project also converts it back into the original text

Project Development

  • The technical development of this project was divided into three phases:
    • Data Load
    • Text to matrix conversion
    • Matrix to text conversion

Data Load

  • The .txt text was provided during the Post-graduation course and can be seen into the project Repository.
  • Below it is possible to read its initial sentences

"De motu Circulari Fluidorum.

Hypothesis.

Resistentiam, quæ oritur ex defectu lubricitatis partium Fluidi, cæteris paribus, proportionalem esse velocitati, qua partes Fluidi separantur ab invicem."

Text to matrix conversion

  • The idea was to convert the text into matrix where its amount of lines and columns depends on the text structure.
    • Each line in the text is a line in the matrix
    • The amount of columns were defined by the line that has the most amount of words.
    • The lines that had fewer words, were be completed with the text "None", as many times as necessary, untill it had the same amount of words as the longest sentence.
    • After that, there was a text matrix, but still with words and not numbers
  • Each word presented in the text vocabulary received a numerical value, creating a "conversion matrix"
  • In possesion of the conversion matrix and the text matrix it was possible to create a new numerical matrix, that represented the text
  • Below it is a representation of the matrix and some informations regarding the numbers used to convert the text and the words related to it:
