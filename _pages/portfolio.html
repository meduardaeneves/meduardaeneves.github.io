This portfolio section provides all the code that I have developed.
All of them have connections to a GitHub repository, allowing access to the raw codes.

They are divided into two categories:

  • Games
  • Personal Projects

GAMES

Some games, to be displayed in the website, were deployed with the help of a low-code platform (Anvil Framework)

Other games created required a GUI interface to work. Because of that, those games will not be able to be played on this website, but it will be provided and ".exe" to allow you to download it.

  • The executable file was created with "Pyinstaller Library"
  • In some cases, your PC provides protection for the apps created like this. If that is the case, you need to exclude the file from the "Real-Time Scanning" section in your PCs firewall protection.
  • If you don't want to modify your PCs protection, you can access the github repository with all the codes that were used to create the app, download them and then play them on your own code editor.
